# ComplyOS school vendor packet

Status: readiness artifact, not legal advice.
Owner: product/privacy/legal + accessibility review.
Review cadence: before any school pilot, district procurement, or student-data integration.

## Purpose

This School vendor packet lists the privacy, Student data, accessibility, and procurement items needed before ComplyOS is sold into schools or used with student records.

## Student data boundary

ComplyOS should treat school/customer data as customer-controlled education records where applicable.

Default routing:

- student and parent/guardian requests route through the school customer;
- school admin authority must be verified before data export/deletion;
- contracts must define whether ComplyOS is allowed to respond directly;
- student data should not be used for advertising, unrelated profiling, or unrelated model training.

## FERPA review items

- school official / vendor role language;
- legitimate educational interest language;
- redisclosure restrictions;
- parent/eligible-student request routing;
- record amendment routing;
- deletion/return terms at contract end;
- audit log and access evidence.

## COPPA review items

- whether users under 13 are in scope;
- whether the school provides consent as permitted for school use;
- direct notice and parent request process where needed;
- data minimization for younger students;
- deletion and retention windows.

## Accessibility procurement items

Before public-sector or school procurement, collect:

- WCAG 2.2 AA audit status;
- keyboard navigation evidence;
- screen-reader testing evidence;
- color contrast evidence;
- PDF/report accessibility plan;
- VPAT or equivalent assessment if requested.

## Customer packet checklist

- data map;
- DPA or student data privacy agreement;
- subprocessor list;
- breach-response contact and notification workflow;
- retention/deletion schedule;
- accessibility evidence;
- support/SLA contacts;
- security evidence packet;
- sample DSR routing workflow.

## Remaining external work

- counsel-approved school terms;
- target-state student privacy review;
- VPAT/accessibility assessment;
- district-specific procurement questionnaire answers;
- production support queue and escalation SLA.
