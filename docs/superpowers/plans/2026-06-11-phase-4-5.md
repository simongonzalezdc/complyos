# Phase 4 and Phase 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the two open roadmap phases by adding operator scheduling, Slack/Teams notifications, release/security checks, PostgreSQL-ready persistence, a live dashboard API, and first-pass SAP SuccessFactors + Cornerstone connectors.

**Architecture:** Keep the existing local-first model. Add small, testable modules around the current CLI, SQLAlchemy repository, connector interface, and FastAPI dependency. New enterprise connectors normalize source payloads into the existing `User`, `Course`, `Enrollment`, and `LearningRecord` models instead of adding a second product path.

**Tech Stack:** Python 3.11+, Typer, FastAPI, SQLAlchemy, httpx, pydantic, pytest, respx.

## Research constraints

- Slack incoming webhooks post JSON payloads to a secret URL and support at least a top-level `text` field.
- Microsoft Teams currently recommends webhook reception through Workflows; the app should post a plain JSON summary that Power Automate can map to a channel message or Adaptive Card.
- SAP SuccessFactors Learning exposes Learning OData APIs and microservices, including user learning history, user assignments, search/user services, OAuth bearer headers, and API throttling guidance.
- Cornerstone supports OAuth 2.0 client credentials; transcript/task APIs expose transcripts, assigned trainings, and `transcript:read` scope.
